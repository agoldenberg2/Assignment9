For this assignment, I used a graph to create a simple social network where people can add friends and see who they are connected with. I think a graph works the best here because friendships can go in many ways, and one person can be friends with many people. Using a graph makes it easier to organize it and not have to follow an order. I don't think a list would work very well here because it stresses information in a sequence and does not clearly show how everyone is connected. A tree wouldn't be the best choice here either because it has a top, and in a friendship group, no one needs to be at the top. Something that caught my attention when doing this was that using an adjacency list made it easy to add new people and friends. I used a dictionary to store each person and a list to keep track of friends. Adding friends was easy, but the program needed to check for duplicates. Printing the network was also pretty easy because I could loop through it all and display everything. Overall, I loved this assignment it helped me grow my knowledge.
